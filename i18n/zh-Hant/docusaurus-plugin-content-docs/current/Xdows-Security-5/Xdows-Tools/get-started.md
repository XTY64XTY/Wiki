# Xdows Tools

Xdows Tools 是 Xdows Security 內建的工具集，提供系統管理和安全輔助功能。產品名稱一律寫作 `Xdows Tools`，不翻譯。

工具列表以索引標籤形式組織，切換索引標籤時有滑動動畫。

## 處理程序管理員 {#ProcessManager}

管理系統中執行的處理程序。

### 檢視處理程序列表

- 列表顯示每個處理程序的**名稱、PID、執行緒數、控制代碼數和記憶體佔用**。
- 支援**列表檢視**和**樹狀檢視**切換，樹狀檢視按父子關係展示處理程序層級。
- 支援**驅動處理程序**模式切換：該模式透過驅動程式取得與操作處理程序，必須先啟用驅動程式防護。
- 頂部提供**搜尋方塊**，可依處理程序名稱或 PID 即時篩選。

### 排序

支援按以下欄位排序：

- 名稱
- PID
- 記憶體
- 執行緒數
- 控制代碼數

### 處理程序操作

右鍵點擊處理程序可執行以下操作：

- **重新整理列表**：重新載入處理程序列表
- **詳細資訊**：雙擊或右鍵選擇可開啟處理程序詳細資料面板
- **暫停處理程序**：暫停處理程序執行
- **恢復處理程序**：恢復已暫停的處理程序
- **結束處理程序**：終止選中的處理程序

## 命令提示字元 {#CommandPrompt}

內建終端機工具，無需開啟外部 cmd 即可執行系統命令。

- **執行命令**：在輸入方塊輸入命令並按 Enter 或點擊「執行」按鈕
- **命令歷史**：使用上下方向鍵（↑↓）瀏覽歷史命令
- **輸出區域**：顯示命令執行結果，支援捲動檢視
- **複製輸出**：可從輸出區域複製內容到剪貼簿

:::note
Xdows Security 的應用程式資訊清單已要求以系統管理員身分執行，命令提示字元隨之以系統管理員權限執行命令。
:::

## 彈窗攔截器 {#PopupBlocker}

自訂規則攔截指定視窗標題和處理程序的彈窗。

### 主開關

頂部切換開關控制彈窗攔截的整體啟停：

- **監控中**：規則生效，匹配的彈窗會被自動關閉
- **已停止**：所有規則暫停，不執行任何攔截

### 規則管理

規則列表顯示每條規則的**標題、處理程序名稱、狀態和啟用狀態**。頂部提供搜尋方塊可依關鍵字篩選規則。

- **新增規則**：根據視窗標題和處理程序名稱新增攔截規則
- **編輯規則**：雙擊規則或右鍵選擇「編輯規則」修改現有規則
- **刪除規則**：右鍵選擇「刪除規則」移除不需要的規則
- **啟用/停用**：單獨控制每條規則的開關狀態
- **規則狀態**：顯示規則的匹配次數和目前狀態
