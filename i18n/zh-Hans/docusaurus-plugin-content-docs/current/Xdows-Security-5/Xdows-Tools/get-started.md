# Xdows Tools

Xdows Tools 是 Xdows Security 内置的工具集，提供系统管理和安全辅助功能。产品名始终写作 `Xdows Tools`，不翻译。

工具列表以选项卡形式组织，切换选项卡时有滑动动画。

## 进程管理器 {#ProcessManager}

管理系统中运行的进程。

### 查看进程列表

- 列表显示每个进程的**名称、PID、线程数、句柄数和内存占用**。
- 支持**列表视图**和**树状视图**切换，树状视图按父子关系展示进程层级。
- 支持**驱动进程**模式切换：该模式通过驱动获取与操作进程，必须先启用驱动防护。
- 顶部提供**搜索框**，可按进程名称或 PID 实时筛选。

### 排序

支持按以下字段排序：

- 名称
- PID
- 内存
- 线程数
- 句柄数

### 进程操作

右键点击进程可执行以下操作：

- **刷新列表**：重新加载进程列表
- **详细信息**：双击或右键选择可打开进程详情面板
- **挂起进程**：暂停进程运行
- **恢复进程**：恢复已挂起的进程
- **终止进程**：结束选中的进程

## 命令提示符 {#CommandPrompt}

内置终端工具，无需打开外部 cmd 即可执行系统命令。

- **执行命令**：在输入框输入命令并按回车或点击"执行"按钮
- **命令历史**：使用上下方向键（↑↓）浏览历史命令
- **输出区域**：显示命令执行结果，支持滚动查看
- **复制输出**：可从输出区域复制内容到剪贴板

:::note
Xdows Security 的应用清单已要求以管理员身份运行，命令提示符随之以管理员权限执行命令。
:::

## 弹窗拦截器 {#PopupBlocker}

自定义规则拦截指定窗口标题和进程的弹窗。

### 主开关

顶部切换开关控制弹窗拦截的整体启停：

- **监控中**：规则生效，匹配的弹窗会被自动关闭
- **已停止**：所有规则暂停，不执行任何拦截

### 规则管理

规则列表显示每条规则的**标题、进程名、状态和启用状态**。顶部提供搜索框可按关键词筛选规则。

- **添加规则**：根据窗口标题和进程名添加拦截规则
- **编辑规则**：双击规则或右键选择"编辑规则"修改现有规则
- **删除规则**：右键选择"删除规则"移除不需要的规则
- **启用/禁用**：单独控制每条规则的开关状态
- **规则状态**：显示规则的匹配次数和当前状态
